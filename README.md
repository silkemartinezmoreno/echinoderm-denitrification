# Denitrification genes in echinoderm biofilm and subcuticular microbiomes

[![DOI](https://zenodo.org/badge/1455852032.svg)](https://doi.org/10.5281/zenodo.24177651)

Code and data to reproduce the results of:

> Martínez-Moreno S, Tirado-Serrano A, Ferrera I, Reche I. *Beyond the host: denitrification genes in echinoderm biofilm and subcuticular microbiomes.* Animal Microbiome (submitted).

The study combines 16S rRNA gene-based functional inference (PICRUSt2) with droplet digital PCR (ddPCR) quantification of the denitrification genes *nirS* and *nosZ* in the epicuticular biofilm and subcuticular microbiomes of echinoderms.

## Quick start

1. Download or clone this repository.
2. Open `echinoderm-denitrification.Rproj` in RStudio, so that all paths are relative to the project folder.
3. Install the R packages (see [Requirements](#requirements)).
4. Run `run_all.R`.

All result tables are written to `results/tables/`. This reproduces every result of the manuscript from the data in `data/`, in a few seconds.

## Workflow

The scripts are numbered in the order of the analysis and of the manuscript.

| Script | Manuscript | What it does | Output (`results/tables/`) |
|---|---|---|---|
| `01_sequence_processing.R` | Methods: Sequencing and data analysis | Raw reads → ASVs (DADA2, SILVA 138.1) → rarefaction → 97 % OTUs | `results/sequence_processing/` |
| `02_run_picrust2.sh` | Methods: Functional inference using PICRUSt2 | Converts the OTU table to HDF5 BIOM and runs PICRUSt2 (command line) | `results/picrust2/` |
| `03_extract_denitrification_KOs.R` | Methods: Functional inference using PICRUSt2 | Extracts the denitrification KOs from the PICRUSt2 output | `data/picrust2/denitrification_KOs_contrib.xlsx` |
| `04_ddpcr_curation.R` | Methods: Data processing | Removes outlier pseudoreplicates and computes copies/ng-DNA per sample | `ddpcr_replicates.csv`, `ddpcr_curated.csv` |
| `05_picrust2_denitrification_genes.R` | Figure 2 | PICRUSt2-predicted abundance of *narG*, *napA*, *nirS*, *nirK*, *norB* and *nosZ* per species | `Fig2_*.csv` |
| `06_ddpcr_sample_types.R` | Figure S1 | *nirS* and *nosZ* in biofilm, subcuticle, seawater and sediment; Kruskal-Wallis and Dunn tests | `FigS1_*.csv` |
| `07_ddpcr_species.R` | Figures 3, 4 and 5 | *nirS*, *nosZ* and *nirS*/*nosZ* ratio per species (11 species) | `Fig3-5_*.csv`, `Fig3_*.csv`, `Fig4_*.csv`, `Fig5_*.csv` |
| `08_picrust2_vs_ddpcr.R` | Figures 6 and 7 | Spearman correlations between PICRUSt2 and ddPCR | `Fig6-7_*.csv` |
| `09_table_S1.R` | Table S1 | Number of samples per species included in each analysis | `TableS1_samples_per_analysis.csv` |

`00_settings.R` holds the settings shared by scripts 04–09: the samples excluded from the analyses, the 11 species shown in Figures 3–5, and helper functions.

`run_all.R` runs scripts 04–09. Scripts 01–03 are not run by default because they need the raw reads and many hours of computation; their output is already provided in `data/picrust2/`.

## Data

| File | Content |
|---|---|
| `data/ddpcr/nirS_<plate>_manual.xlsx`, `nosZ_<plate>_manual.xlsx` | ddPCR results exported from QX Manager (one file per plate; three pseudoreplicates per sample). The concentration used is the last column, copies/ng-DNA. |
| `data/ddpcr_sample_metadata.csv` | For each ddPCR sample: sequencing code (`code`), species (`sp`), class (`clases`), compartment (`type`) and sampling site. `code` links ddPCR and PICRUSt2 data; `X` means the sample was not sequenced. |
| `data/sample_metadata.xlsx` | Metadata of all 305 sequenced samples. |
| `data/sequencing_runs.csv` | Sequencing run of each sample (columns `sample` and `run`). Samples were sequenced in two runs; script 01 learns the error rates of each run separately. |
| `data/picrust2/denitrification_KOs_contrib.xlsx` | PICRUSt2 contributions of each OTU to the denitrification KOs, per sample (output of script 03). |

Sample names follow the pattern `<site>_<species code><individual>_<compartment>`, e.g. `1_HT2_S`. Compartment codes: `H` = biofilm, `S` = subcuticle, `AG` = seawater, `SED` = sediment.

### Data not included in this repository

- **Raw sequences**: NCBI Sequence Read Archive, BioProject [PRJNA1454003](https://www.ncbi.nlm.nih.gov/bioproject/PRJNA1454003). Download them into `data/raw/` to run the full processing from script 01.
- **SILVA reference**: `silva_nr99_v138.1_wSpecies_train_set.fa.gz` from [Zenodo](https://zenodo.org/records/4587955), into `data/reference/`.
- **OTU table, OTU sequences and PICRUSt2 output**: generated by scripts 01 and 02 from the raw sequences. The PICRUSt2 output `pred_metagenome_contrib.tsv` is very large (tens of GB), so it is not included; script 03 reduces it to the denitrification KOs, which are provided in `data/picrust2/denitrification_KOs_contrib.xlsx`.


## Requirements

Analysis (scripts 04–09) was run with R 4.2.2 and these packages:

```r
install.packages(c("readxl", "dplyr", "dunn.test", "data.table", "openxlsx"))
```

`data.table` and `openxlsx` are only needed for script 03.

Sequence processing (script 01) also needs `dada2`, `DECIPHER` (Bioconductor), `tidyverse` and `vegan`:

```r
install.packages(c("tidyverse", "vegan", "BiocManager"))
BiocManager::install(c("dada2", "DECIPHER"))
```

PICRUSt2 (script 02) runs on Linux, macOS or WSL on Windows, installed with conda:

```bash
conda create -n picrust2 -c bioconda -c conda-forge picrust2
```

The exact package versions of the last run are saved by `run_all.R` in `results/sessionInfo.txt`.
